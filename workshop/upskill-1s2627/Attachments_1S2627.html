Topic Outline

*Paced for beginners; stretch notes marked optional.

Part A - SheetSkills: Companies You Already Recognize

Working metaphor: A slightly messy table of PH companies you know from malls, banks, telcos, and food. Make it readable and find one honest insight.

Progression: Start with uneven headers, blank yields, mixed formats. End with a sorted/filtered sheet, one chart, and one sentence such as "Among complete rows, ..."

Guide questions: Why is my formula showing as text? How do I fill a formula down? What does a blank dividend yield mean for my chart? How do I keep only complete rows? How do I chart yield for companies I know? When should a very high yield make me suspicious?

Topics (core): spreadsheet interface and freeze panes; sort and filter; basic formatting; simple formulas (IF, IFERROR); one chart; missing-data hygiene. Optional stretch: XLOOKUP / split text to columns.

Workflow: meet familiar tickers (SM, JFC, BDO, GLO, MER, ...); clean labels and formats; filter to data_complete = yes; chart a small subset; write one careful insight with a caveat.

Tangible output: cleaned sheet tab + 1 chart + 1-2 bullet insights in plain Filipino or English.

Part B - Colab Camp: Filter a Shortlist (No Install)

Working metaphor: Same companies in a notebook. Run cells, count missing values, apply a rule such as "complete rows with yield above X."

Progression: Start with Colab + CSV already linked. End with a shortlist table you can explain in one minute.

Guide questions: How do I run a cell? How do I see the first rows? How do I count missing yields? How do I keep rows that match my rule? How do I sort the shortlist? What disclaimer should I remember before ranking companies?

Topics (core): Colab tour; read_csv / head / shape; missing values; boolean filters; sort + simple bar chart; export or screenshot. Optional stretch: local VS Code; compare two tickers; one-slide glimpse of a fuller PSE pipeline.

Workflow: open Colab and run setup; load the familiar-ticker table; missingness check; apply a simple screen (speaker defaults first); customize one threshold with a partner; optional 30-60 second share-out.

Tangible output: shortlist of recognizable companies + the rule you used + one data caveat.

Guardrails: offline curated snapshot only; no ROIC or ML in the main path; educational disclaimer on slide 1 and notebook top; completed notebook copy if a laptop fails; speaker is not the MC.
